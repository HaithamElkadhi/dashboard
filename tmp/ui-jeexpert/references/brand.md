# Marque JEEXPERT

Source : `JEEXPERT_Brand_Guidelines.pdf`, octobre 2026, pages 1–8.

## Logo et messages — pages 1–3, 5, 8

Le wordmark complet est destiné aux en-têtes de site, présentations et supports de marque. Le J simplifié convient aux icônes, avatars et favicons. La version inversée est blanche sur bleu profond ; le J possède un accent azur.

Respecter les formulations :

- Slogan : **OUR EXPERTISE, YOUR FUTURE**.
- Hashtag de campagne : **#AchieveMore**.
- Valeurs : **Clarity • Trust • Guidance**.

Le slogan accompagne les grandes compositions ; il reste séparé du dessin du logo. Omettre slogan et hashtag sur petites icônes, favicons et tampons. Pour l’application ERP, ne pas ajouter systématiquement des messages de campagne aux contrôles fonctionnels.

Conserver les proportions et lettres originales. Pas d’étirement, rotation, contour ajouté, ombre ni substitution typographique. Fond dégagé ; espace libre d’au moins **un quart de la hauteur du logo** sur chaque côté. Pour un avatar, garder tout le J dans les **70 % centraux** du carré.

Largeur minimale suggérée du wordmark : **120 px** à l’écran ou **25 mm** en impression. En dessous, utiliser le J. Garder le slogan lisible ou l’omettre.

## Palette et typo — page 4

| Usage | Hex | RGB |
| --- | --- | --- |
| Bleu profond | `#173B65` | 23 / 59 / 101 |
| Azur clair | `#80C4EA` | 128 / 196 / 234 |
| Blanc | `#FFFFFF` | 255 / 255 / 255 |

Poppins SemiBold pour les titres, Medium pour les boutons, Regular pour le corps. Le wordmark n’est pas composé en Poppins. Employer bleu sur blanc ou blanc sur bleu pour le texte essentiel, azur pour les accents.

## Formats de référence — pages 5–8

| Application | Point de départ |
| --- | --- |
| Icône d’app | Source 1024 × 1024 px, J sans slogan |
| Avatar social | 1080 × 1080 px, vérifier la découpe circulaire |
| Publication sociale | 1080 × 1080 px, wordmark et slogan ; hashtag séparé |
| Site | Wordmark, SVG préféré si un vrai master existe |
| Favicon | J simplifié à 16, 32 et 48 px ; monochrome à 16 px |
| Carte de visite | 85 × 55 mm, fond perdu 3 mm, marge sûre 4 mm |
| Bouteille | Logo/J environ 25–40 mm de large |
| Tampon | Monochrome environ 30–40 mm, sans détails fins |
| T-shirt | Logo/J poitrine environ 80–110 mm |
| Bannière | Exemple 200 × 80 cm, gabarit fournisseur prioritaire |
| Roll-up | Exemple 85 × 200 cm, laisser la base dégagée |

Ces tailles sont des points de départ, pas des obligations de plateforme ou fournisseur. Impression : utiliser le profil ICC et les marges du fournisseur et faire valider une épreuve physique. Les versions monochromes fusionnent l’accent azur avec la forme principale.

Les PDF contiennent des concepts et mockups, **pas des masters vectoriels**. Les PNG fournis ne deviennent pas des SVG par changement d’extension. La préparation de vrais masters vectoriels est un travail distinct, à effectuer seulement si demandé.
